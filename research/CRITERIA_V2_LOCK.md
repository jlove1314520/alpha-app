# CRITERIA_V2_LOCK.md — FDR 校正標準鎖定（criteria_v2，2026-08-25）

**這份檔案的作用**：在對 `TRIALS_LEDGER.md` 既有 37 筆試驗套用新校正方法、重新評分之前，先把新標準的公式、參數、A/B 分類規則寫死存證並 git commit。之後的重新評分只能套用這裡寫死的規則，不能看到重算結果後回頭調整公式或 q 值。

**誠實揭露一點**：這份鎖定不是「我先閉眼睛選一個公式，再去看資料」意義上的純淨盲測——公式（BH-FDR）跟 q=0.10 是使用者在指示裡直接指定的，不是我看過 37 筆結果後反推出剛好能救回想要的候選的參數。之所以還是需要「鎖定」這個動作，是為了防止**後續重算過程中**因為看到某些試驗差一點點就能翻盤、而去微調 A/B 分類的邊界（例如放寬「樣本數<100」或悄悄把某個結構性失敗改判為單純門檻失敗）。鎖定的對象是「規則寫死之後不能再動」，不是宣稱規則本身跟結果無關。

---

## 1. 多重比較校正方法

**Benjamini-Hochberg (BH) 程序，FDR 控制水準 q = 0.10。**

- 每一軌（TW / US / FUT）**各自獨立**的假設家族，`m` = 該軌**全部**已做過統計檢定的試驗數（包含目前判定 PASS/CHEAP_PASS/EXPERIMENTAL/FAIL 的所有列，不是只算 FAIL 的），跨軌不共用分母。
- 家族內全部試驗的 p 值由小到大排序：p(1) ≤ p(2) ≤ ... ≤ p(m)。
- 找出最大的 k，使得 p(k) ≤ (k/m) × q。
- 排名 1 到 k（含）的試驗視為 FDR 顯著；k 之後的維持不顯著。
- 若同一個假說有多次重測（例如提高隨機抽樣解析度的重測），**用最新、解析度最高的那一次測量結果**代表這個假說進入家族排序，不重複計入同一假說的舊測量（避免同一假說佔用家族裡兩個名額，人為推高或壓低其他試驗的排名分母意義）。這條跟 `TRIALS_LEDGER.md` 既有「累積校正(n=X)」的計數習慣（把每一次重測都算一列）不同——**本次 FDR 重新評分的家族大小 m，採用「去重後的假說數」，不是「原始列數」**，這點在下方對照表會列清楚每一軌實際用的 m。

## 2. p 值還原規則

- p ≈ 1 − 百分位 / 100。
- 若百分位 = 100.0（等於全部隨機抽樣都輸給真實策略），代表真實 p < 1/(N+1)（N=隨機抽樣次數）；沒有更精確數字時，用 N=200（這個專案目前最常見的單批抽樣次數）近似，取 p ≈ 1/201 ≈ 0.005 作為上界代表值，而不是直接當成 p=0。
- 找不到可還原的統計量（例如只有質化描述、沒有留下百分位數字）的試驗，標記「無法重算，需重跑」，不用猜的填數字。

## 3. A/B 分類規則（只有 A 類能進入 FDR 重新評分）

**A 類「純門檻失敗」**：統計方向正確、（若有 train/val 切分）訓練期與驗證期方向一致、報酬分布不集中在少數期間/少數合約，只是沒過當時的嚴苛門檻。

**B 類「結構性失敗」，符合下列任一者，一律維持否決，禁止用新門檻復活**：
- 訓練期與驗證期預測方向反轉（這類**不是**直接判否決，是轉去下面「情境依賴候選」流程另案處理，不進入這份 FDR 復活評分）。
- 報酬高度集中於少數年份/少數合約。
- 隨機對照組表現優於策略本身（即百分位明顯低於 50，尤其 <20）。
- 樣本數過少（原始資料點/交易筆數 <100；不是指單純的日曆天數）。

**未分類到 A 也未觸發任何 B 條件、但直接判定資料本身不足以下結論**（例如 26/28 這類「沒有證據支持方向性」但也沒有觸發任何 B 條件的極弱訊號）：仍歸入 A 類參與 FDR 排序，交給統計結果本身判斷，不用人工預先剔除。

## 4. 用詞紀律

- FDR 重新評分後新變成顯著的試驗，一律標「**待複驗候選（CANDIDATE）**」，不可標「PASS/已驗證」。必須再通過：情境分群檢驗 → 成本敏感度 → alpha/beta 顯著性關卡，才能談 holdout。
- 絕不可因為這次重新評分就直接上架到 App（`scores.json`／`score_v2.py`）或紙上前測系統（`STRATEGY_PAPER_TRADING` 相關，若已存在）。
- 這次重新評分是**更換多重比較校正方法**的結果，不是新證據——沒有重新抓資料、沒有重新跑隨機控制組，是把既有的百分位數字套進新公式。這句話要原封不動出現在 `REPORT.md` 的記錄裡，不能省略。
