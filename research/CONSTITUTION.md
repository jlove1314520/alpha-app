# 台美股自動交易 App 開發建議報告
### 提煉自 Cybex 加密貨幣量化機器人半年開發經驗

> 用途:交給另一個開發 session/agent 當「開工前必讀」。目的不是給你策略,是讓你**少走 Cybex 已經走過的冤枉路**,並標出股票與加密貨幣**本質不同、不能照抄**的地方。
> 免責:本文為研究與工程開發建議,**非投資建議、非稅務/法律意見**。涉及券商 API 條款、稅務、當沖/放空法規,務必另外諮詢專業人士與券商官方文件。

---

## 0. 一句話心法
**「看起來會賺」和「真的會賺」是兩回事。** Cybex 花了 240+ 輪研究,最有價值的產出不是某個策略,是一套**逼自己誠實**的驗證紀律 + 一套**讓 bug 無法靜默復發**的工程防線。這兩樣直接搬到股票 app,價值遠大於任何單一訊號。

---

## 1. 可直接沿用的 Cybex 資產(不用重新發明)

1. **Weinstein 四階段分析**——它本來就是**為股票發明的**(Stan Weinstein 的《Secrets for Profiting in Bull and Bear Markets》講的是股市)。Cybex 的 `stage2_scanner`(全市場掃第二階段 + 大盤總體閘門 + 動量選前 K 名 + 三層風控)這套骨架,套回股票**比套加密還自然**。
2. **驗證管線**:train / validation / **holdout(聖域,一次性)** 三段切分 + 隨機控制組 + 成本敏感度(1x/2x/3x) + leave-one-out 逐期 + 跨週期一致性 + 多子期間方向一致。這套照搬。
3. **紙上前測 + 影子帳本架構**:每個候選先開一本 $X 虛擬帳本、接真實前向資料跑,由**真未來**當最終裁判,而不是只信回測。
4. **健檢 + 稽核恆等式**:每日/每三日自動健檢 + audit 恆等式(權益=現金+已實現+未實現、每個持倉都能對應到一筆進場記錄…),任何一條不 PASS 當場紅字。
5. **Meta 規律**(Cybex 實證):**連續縮放的調節器有效,二元開關通常沒用;已完整堆疊的系統再加東西通常沒幫助;「速度/加速度」常勝過「水位」。** 這些是探索方向的先驗,能省很多輪。

## 2. 踩過的雷 A:方法論陷阱(每一條都有 Cybex 實際案例,務必內建防呆)

1. **holdout 污染(最痛的一個)**:Cybex 有個「post2024 真樣本外」檢查用了上百次,後來才發現它的日期邊界**和 holdout 完全重疊**——等於偷看了上百次 holdout,整套驗證的公信力被侵蝕。
   → **鐵則:holdout 要在程式層物理隔離**(資料載入預設就截斷在 holdout 邊界前,只有唯一一個「正式一次性測試」函式能解鎖),不能只靠「文件上說不准看」。人一定會不小心看。
2. **多重比較 / 拿 OOS 當驗證集**:反覆拿同一塊樣本外去篩候選、留下剛好通過的,本身就是過擬合。搜越多,通過門檻要越高(deflated Sharpe / 多重比較校正)。
3. **四大「統計偽影」陷阱**(Cybex 測了 17 個 on-window 機制才歸納出來):任何新機制若本質是①減少換手 ②改變曝險力道 ③縮小候選池 ④替換排名前段的幾個成員,**幾乎必然靠運氣在樣本內通過、被隨機控制組拆穿**。
   → **鐵則:每個候選都要打贏「同樣動作、隨機挑對象」的控制組**,證明賺的是訊號本身不是副作用。
4. **日曆假高原 / 孤立尖峰**:重平衡天數網格上出現單點暴衝(rebal=7 特別高、鄰居很低)常是 aliasing,不是真高原。→ 一律用細網格確認是「一整片」而非單點。
5. **聚合口徑 bug**:「先算各期年化再平均」會灌水,要用「拼接成一條連續曲線再算一次年化」。
6. **「跨參數看起來穩健」不等於真**:跨週期一致的優勢也可能是共用的假象,要拆成子期間分別驗證。
7. **事前綁定通過標準,絕不事後移動門柱**:Cybex 三個候選 holdout 差一根寒毛沒過(MDD 略深),當下**沒有**放寬標準讓它們過——因為改標準就是動量尺。標準要在測試前寫死。
8. **regime 專屬的 edge 常不泛化**:某段歷史路徑剛好有利的機制,換到真沒看過的年份就翻負。真樣本外(尤其涵蓋不同市場環境)才是裁判。
9. **sanity check**:任何新機制的「關閉狀態」必須能逐位重現凍結基準(diff=0),否則是實作污染不是真效果。

## 3. 踩過的雷 B:工程 / 維運陷阱(股票 app 一樣會中)

1. **繼承「幽靈部位」**:帳本初始化時繼承了回測終態的持倉、卻沒有前向進場記錄,污染 MDD/損益。→ 前向帳本**一律空手起跑,只認前向自己開的單**;必須延續的部位要重定基到起跑日價格並明確標記。
2. **交易記錄器靜默漏記**:Cybex 一個全域 `last_run_date` 過濾器**吞掉了 7000+ 筆交易**都沒人發現。→ per-book 追蹤 + 加一道 audit 恆等式:每個持倉都必須查得到對應進場記錄,否則紅字。
3. **NaN 進出場價 → 假出場**:未收盤 K 棒混進資料造成幻影平倉。→ 丟棄未收盤 K 棒 + NaN 價格過濾。
4. **顯示落後一天**:資料日 vs 未收盤當日 K 棒的混淆。→ 明確標示「當日未收盤,收盤後更新」。
5. **外部抓資料卡死整條管線**:單一 API 連線 TCP 卡住、`timeout` 沒生效,整個更新凍住。→ 用執行緒硬逾時包起來,逾時就沿用本機快照繼續。
6. **沒有 OS 層級排程**:只靠一支常駐程式活著,當掉就靜默 stale。→ 註冊系統排程(開機補跑),不要依賴單一進程。
7. **密鑰同步外洩風險**:API key / 憑證絕不放進會同步到雲端的資料夾。
8. **session 是消耗品、檔案才是本體**:所有狀態、進度、決策寫進檔案,換 session/agent 能無痛接手。
9. **每修一類 bug,就加一條永久稽核恆等式**——讓那類錯誤以後一出現就被當場抓到,不靠人肉記憶。

---

## 4. 不能違反的鐵律(直接繼承,寫進新 app 的 CLAUDE.md/憲法)

1. holdout 程式層物理隔離,一次性、測過即焚,人工批准才碰。
2. 事前綁定通過標準,不事後移動門柱。
3. 每個候選都要打贏「隨機控制組」。
4. **只用 point-in-time 資料,零未來函數**(股票這條比加密嚴格得多,見第 5 節)。
5. 宇宙必須**無存活者偏差**(含已下市/下櫃/被併購/破產的股票)。
6. 真實摩擦全部計入(手續費/稅/滑價/市場衝擊/借券成本/漲跌停無法成交)。
7. 真樣本外 / live 前向是唯一最終裁判,回測只是初篩。
8. **絕不自動下真單、絕不自動搬錢**——真實證券下單要人工明確執行,尤其涉及法規與券商條款。
9. 每類 bug 配一條永久稽核恆等式。

## 5. 股票 vs 加密貨幣:本質不同、不能照抄的地方(這節最重要)

| 面向 | 加密貨幣(Cybex) | 股票(台/美) |
|---|---|---|
| 交易時間 | 24/7 連續 | 固定盤別、有收盤、盤前盤後流動性稀薄 |
| **隔夜/週末跳空** | 幾乎無(連續交易) | **重大風險**:財報/新聞造成跳空,停損跳空穿價 |
| 漲跌限制 | 無 | 台股 **±10% 漲跌停**(漲停買不到、跌停賣不掉,流動性瞬間消失);美股無漲跌停但有 **LULD 熔斷/暫停交易** |
| 放空 | 永續合約,容易 | **困難且受規管**:需借券(有無券源)、美股 SSR 上漲檔限制、台股平盤下不得放空(部分)、軋空風險 |
| 基本面 | 幾乎沒有 | **有**:財報、EPS、營收、本益比——但**財報會事後重編、有公布時間差**,必須用 point-in-time 基本面,否則嚴重未來函數 |
| 公司行動 | 無 | **分割/股利/減資/合併/下市**——回測**必須用還原股價**,除息跳空要正確處理 |
| 存活者偏差 | 有(下市幣抓不到) | **更嚴重且更貴**:破產/下市/被併股票的歷史資料需付費 PIT 資料集(如 CRSP) |
| 結算 | 即時 | **T+2(台股)/ T+1(美股)**,影響資金可用與當沖規則 |
| 當沖規則 | 無 | 台股現股當沖有「先買後賣/先賣後買」限制、處置股限制;美股 **PDT 規則**(帳戶<$25k → 5 日內最多 3 筆當沖) |
| 稅 / 費 | 交易所手續費 | 台股手續費 0.1425%×2 **+ 證交稅 0.3%(當沖 0.15%)**,成本明顯;美股佣金近零但有價差/衝擊,**wash sale 洗售規則**影響報稅 |
| 市場結構 | 散戶為主、24h、無漲跌停 | 機構林立、因子(動量/價值/品質/低波)被研究數十年,**alpha 更薄、更擁擠** |
| 總體驅動 | 相對自成一格 | **強烈受總體影響**:利率/Fed/CPI、大盤 regime、類股輪動比加密更主導 |
| 資料 | 交易所 API 免費但雜 | 乾淨的 PIT/基本面/還原價/無偏宇宙**多半付費、有授權限制** |
| 容量/衝擊 | 大幣流動性佳 | 小型股策略**無法放大**(市場衝擊會吃掉 alpha),容量是硬約束 |

**一句話:** 加密的核心風險是波動與方向;股票多了**隔夜跳空、公司事件、法規/稅、放空受限、資料偏差與授權**這幾座山。**Cybex 的「只在對的 regime 開單」哲學可以搬,但「進出場摩擦模型」要幾乎全部重寫。**

## 6. 台股專屬清單(容易被忽略的坑)
- **漲跌停無法成交**:回測若假設漲停買得到、跌停賣得掉,績效嚴重灌水。要模擬「觸及漲跌停時流動性歸零」。
- **處置/警示股**:被打入分盤交易(每 5~20 分鐘一次撮合),下單假設要改。
- **證交稅 0.3%** 是台股最大隱形成本,高換手策略常被它吃到轉負——**成本敏感度一定要把稅算進去**。
- **T+2 交割**與**當沖資券配對**規則,影響資金運用與可否當沖。
- **券商 API**(如群益、元大、富果 Fugle、永豐 Shioaji…)各有權限、憑證、流量、模擬環境差異——先確認**有沒有官方模擬下單**,紙上前測階段用它。
- 除權息旺季的**除息跳空**要用還原股價處理,否則誤判成暴跌。

## 7. 美股專屬清單
- **PDT 規則**:小資帳戶(<$25k)5 個交易日內最多 3 筆當沖,超過會被限制——**策略換手頻率要先受此約束**。
- **SSR(放空上漲檔限制)**、**locate 借券要求**:放空邏輯不能照搬加密永續。
- **wash sale 洗售規則**:30 天內買回同標的,虧損不能抵稅——影響回測的稅後報酬與實際操作。
- **財報跳空 / 盤前盤後**:earnings 當天跳空是主要風險也是主要 alpha 來源(PEAD)。
- 佣金雖近零,但**價差 + 市場衝擊 + 借券利息**仍是真成本。

## 8. 建議研究方向(股票專屬、加密沒有的 alpha 來源)
1. **PEAD(財報後漂移)**:財報意外後價格延續數週漂移,是股市**有數十年文獻、加密沒有對應**的異常。需要 PIT 財報 + 精確公布時間戳。
2. **因子選股**(動量 / 價值 / 品質 / 低波 / 規模)——但要**用 PIT 基本面**、控制擁擠度與容量,別直接抄學術因子(已被套利)。
3. **類股 / 產業輪動 + 總體 regime overlay**:用大盤 200 日均線 / 廣度 / VIX / 殖利率曲線當總體閘門(等同 Cybex 的 BTC 第二階段閘門,但換成 SPX/加權指數)。
4. **事件驅動**:earnings、財測上修、納入指數、庫藏股——都有明確時間點與可驗證的反應。
5. **產業內統計套利 / 配對交易**:同產業共整合配對(記得用 PIT + 嚴格檢定,Cybex 的 coint_pairs 經驗:Bonferroni 校正後常全軍覆沒,別被樸素 p 值騙)。
6. **Weinstein 第二階段掃描直接移植**:這是最自然的一條,骨架現成。

## 9. 資料與合規(開工前先確認,別做到一半卡死)
- **先解決資料源**:要 point-in-time、還原股價、含下市股、基本面帶正確公布時點。免費資料多半有存活者偏差或未來函數,**這是股票專案最大的隱形成本,先預算**。
- **券商 API 條款**:自動下單是否允許?流量限制?有無模擬環境?憑證更新機制?
- **法規/稅**:當沖、放空、PDT、洗售、證所/證交稅——**諮詢專業人士**,不要靠 AI 或網路二手資訊當定論。
- **絕不讓程式自動下真單/搬錢**:訊號可以自動算,真實下單留給人工按確認,或至少有多重人工閘門。

---

## 10. 建議開發順序(里程碑)
1. 先搞定**無偏差 PIT 資料管線**(這步最容易被低估)。
2. 建**驗證框架**(train/val/holdout 物理隔離 + 隨機控制組 + 成本/稅模型 + 摩擦模型)——**先於任何策略**。
3. 移植 **Weinstein 第二階段掃描**當第一個 baseline 引擎,跑完整關卡。
4. 建**紙上前測 + 影子帳本 + 健檢 + audit 恆等式**基礎設施。
5. 再逐一挖股票專屬 alpha(PEAD / 因子 / 輪動),每個都走同一套關卡。
6. 全程:誠實記錄正負結果,session 換手靠檔案,永不自動下真單。

---

**核心一句:把 Cybex 的「驗證紀律 + 工程防呆」整包搬過去,策略重新挖;但進出場摩擦、資料偏差、法規稅務這三塊,股票要當全新專案從頭做,不能沿用加密的假設。**
