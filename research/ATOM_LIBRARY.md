## 原子清單（24個：14個個股原子＋10個基準原子，零參數、零前視）

| 原子 | 定義 | 說明 |
|---|---|---|
| `o` | 開盤價（還原後） | 原始欄位 |
| `h` | 最高價（還原後） | 原始欄位 |
| `l` | 最低價（還原後） | 原始欄位 |
| `c` | 收盤價（還原後） | 原始欄位 |
| `v` | 成交量 | 原始欄位，未還原（量本來就不需要除權還原） |
| `amt` | 成交金額 | 原始欄位 |
| `body` | `c − o` | 實體，正＝收紅，負＝收黑 |
| `upper_sh` | `h − max(o,c)` | 上影線，恆≥0 |
| `lower_sh` | `min(o,c) − l` | 下影線，恆≥0 |
| `range` | `h − l` | 當日振幅，停牌鎖死時為0（非NaN） |
| `close_loc` | `(c−l)/(h−l)` | 收盤在區間的相對位置，值域[0,1]；**range=0時回NaN**（鎖死無意義） |
| `gap` | `o − delay(c,1)` | 跳空，第一筆為NaN |
| `true_range` | `max(h,c₋₁) − min(l,c₋₁)` | 真實波幅，含跳空缺口，第一筆為NaN |
| `vwap` | `amt / v` | 量價均值，**停牌無量時回NaN**（不是0） |

理由：`ts_corr`簽名收兩個Series，但原本ATOMS裡沒有大盤，導致
`relative_strength`家族在原子層缺席——那既是既有因子之一，也是天條二
（對標0050）的核心。

| 原子 | 定義 | 說明 |
|---|---|---|
| `b50_o/h/l/c/v` | 0050開高低收量 | `adjust.adjusted_price_series("0050")`真實序列，非重建 |
| `btx_o/h/l/c/v` | TAIEX開高低收量 | `TaiwanStockPrice`原始值，TAIEX是指數無除權息可言 |

**合約差異**：這10個原子要求呼叫端的`df`額外帶`"date"`欄位（其餘14個

「大盤當天憑空變成0」）。個股日期早於大盤資料起點時正確答案是NaN，
不外插。

## 算子清單（19個：17個原版＋2個2026-09-19補件）

### 時序算子（11個，n∈{1,5,20,60}）

| 算子 | 定義 | 邊界情況 |
|---|---|---|
| `delay(s,n)` | 往前n期的值 | 前n筆為NaN |
| `delta(s,n)` | `s − delay(s,n)` | 前n筆為NaN |
| `ts_mean(s,n)` | 滾動平均 | 前n-1筆為NaN（`min_periods=n`） |
| `ts_std(s,n)` | 滾動標準差 | n=1恆為NaN（單點無標準差） |
| `ts_max(s,n)` | 滾動最大值 | 同上 |
| `ts_min(s,n)` | 滾動最小值 | 同上 |
| `ts_rank(s,n)` | 窗口內當下值的百分位排名[0,1] | n=1恆為1.0（退化情況） |
| `ts_sum(s,n)` | 滾動加總 | 同ts_mean |
| `ts_corr(x,y,n)` | 滾動相關係數 | n=1恆為NaN（標準差0，相關無定義） |
| `ts_argmax(s,n)` | 窗口內最大值的相對位置 | 同ts_mean |
| `decay_linear(s,n)` | 線性衰減加權平均，`w_i∝(n−i)`(i=0最近) | 窗口內任一期NaN則整體NaN；n=1退化為自身 |

### 橫斷面算子（3個）

| 算子 | 定義 | 邊界情況 |
|---|---|---|
| `rank(cs)` | 同日橫斷面百分位排名[0,1] | 全部值相同時排名仍遞增（資料本身無鑑別力，非本函式責任） |
| `zscore(cs)` | 同日橫斷面z-score | 標準差為0時回NaN（不是0，避免誤讀成「剛好平均」） |
| `ind_neutral(cs,industry)` | 扣除同產業當日平均 | 單檔產業組扣自己恆為0（無法跟同業比較的誠實反映） |

### 純量算子（5個）

| 算子 | 定義 | 邊界情況 |
|---|---|---|
| `sign(s)` | 正負號 | 標準numpy行為 |
| `abs(s)` | 絕對值 | — |
| `log1p(s)` | `log(1+x)` | x≤−1時為−inf/NaN，如實暴露不吃掉 |
| `ratio(x,y)` | `x/y` | y=0時回NaN（不是inf或0） |
| `mul(x,y)` | `x×y` | NaN傳播（含`0×NaN=NaN`不是0） |

## 單元測試涵蓋情境

`ATOM_LIBRARY.py::self_test()`對每個原子/算子至少一項斷言，並專門涵蓋
四類邊界情況（含新補的`mul`/`decay_linear`/基準原子三項，沿用同一套
四情境）：
1. **NaN傳播**：序列開頭（`delay`/`delta`/`gap`/`true_range`第一筆）、
   窗口不足`min_periods`、`mul`/`decay_linear`任一輸入含NaN。
2. **除零**：`close_loc`/`vwap`/`ratio`的分母為0；`mul`的`0×NaN=NaN`
   （不是0，這是「不知道」不是「確定是零」）。
3. **停牌**（量/額為0，價格鎖死一價）：`vwap`回NaN、`range`為0、
   `close_loc`回NaN；`mul`遇量=0正常回0（量本來就是0，不是缺值）；
   `decay_linear`窗口內含NaN整體回NaN不硬湊。
4. **漲跌停鎖死**（h=l=c）：`close_loc`回NaN、`body`為0；`decay_linear`
   對常數序列回該常數本身（非除零壞掉）；基準原子對齊時個股/大盤
   日期不完全重疊用forward-fill延續前值。

執行`python research/ATOM_LIBRARY.py --self-test`目前**全數通過**
（24個原子、19個算子）。
