## 0. 問題與輸出（不是找贏家）

問題：「哪些**零件**在許多不同組合裡穩健地有貢獻」，不是「哪個組合最賺」。
輸出 `research/COMPONENT_ROBUSTNESS_MAP.md`：只報**零件層級**的貢獻分布。
**硬性紀律（原文照抄，無例外）**：
1. 禁止報告、也不准寫進任何檔案「最佳組合是哪一個」（含 `jsonl` 中間檔只准存每格數字，
   報告與 commit 訊息不得排序點名單一格）。

3. **只用 TRAIN 期**（`validation/holdout.py::TRAIN_END = 2020-12-31`）。VAL 完全不碰，holdout 更不准碰。
   跑前跑後各 `assert` 一次資料最大日期 ≤ TRAIN_END，並呼叫 `holdout.assert_no_holdout_leakage`。

### 1.1 因子池（事前寫死，與任何績效無關）

`eps_family`、`revenue_surprise`、`low_vol`、`rev_accel`、`quality_roe_stability`、`rel_strength`、`ma_breakout`
（7 個成分；`eps_family` = `f_eps_growth` 與 `f_eps_surprise` 平均，沿用 v2 `_raw_components`）。

**入池理由**：全部只靠「已快取的價格／財報／月營收」即可算出，**零新增 API 呼叫**
（`portfolio_backtest_v2_bigsample.py` 的零 API 安全樣本池原則）。**排除**：`value_pe`（PER 資料不在回補涵蓋範圍、
會觸發 FinMind 額度）、`value_pb`（PIT 安全性未驗證，`factors.py` 檔頭揭露）、`foreign_streak`／`inst_flow`
（三大法人需 API）。**入池與否不是因為它們過去 IC 好壞**——沒有用任何績效挑選因子。

**入池前兩道機械式檢查（只看資料，不看績效；失敗處理事前寫死）**：
1. **覆蓋率**：某成分在 TRAIN 期橫斷面非空比例中位數 <60% → 該成分**移出池**（不重抽補位）。
2. **同家族合併**：在 TRAIN 期橫斷面 rank 相關（每個快照算 Spearman、取時間平均）任兩成分 |r|>0.7
   → 視為同一家族（`CLAUDE.md` 七之三「同家族只算一個」），**保留 TRAIN 覆蓋率較高者，平手取字母序在前者**，另一個移出池。
3. **池大小下限**：檢查後池 <5 個成分 → 本項標 `- [!]` BLOCKED（原因＝因子池不足以支撐隨機化，
   需總司令裁示要不要接 API 補因子），**不放寬門檻、不硬跑**。

## 2. 回測設定（沿用既有引擎，一個字不改邏輯）

  （對齊點寫進報告；不對齊不得比較）。

  `[自行裁量]`：走 fallback 時報告**首段**必須寫這行但書——
  **「此池由『今天仍有快取資料』的股票組成，存在存活者偏誤；`low_vol`／`quality_roe_stability` 這類

## 3. 每格記錄的指標（只存數字，不排名）

- **主指標 `m`**：年化超額報酬 % = 策略年化報酬 − TAIEX 買進持有同窗年化（`buy_and_hold_index_pct` 換算年化）。
  分別記 `m_gross`（0×成本）與 `m_net`（1×成本）。
- 描述用：MDD、Sortino、交易筆數、平均年換手率、實際起訖日。
- **1a-0c 牛熊制度**：本圖是「零件貢獻分布」，不是單一策略判定，故**不強制逐段制度表**；
  但每格另存「TRAIN 內各多頭段／空頭段（依 `REGIME_CONDITIONS.md` 鎖定窗口）報酬」，供零件.三取用，
  報告只在**零件層級**加報「該成分在空頭段的中位貢獻」為描述性欄位，**不進判定**。
- **1a-0b 檢定力前置關卡**：本圖不是對市場宣稱 alpha 的檢定，是零件貢獻的**分布描述**，該關卡不適用；
  但**零件.三**（少數組合的六關判定）動工前必須照 1a-0b 做（寫進零件.三規格，不在此處）。

## 4. 貢獻統計（事前定義）

對每個成分 c、每個換倉頻率 k（monthly／quarterly，各 120 格，兩種加權合併）：
- A = 含 c 的格；B = 不含 c 的格（同頻率）。
- 對 i∈A：`Δ_i = m_i − median(m_B)`（各自對毛、淨兩種 m 各算一次：`Δ_gross`、`Δ_net`）。
- 報告：`median(Δ)`、IQR、**正貢獻比例** = mean(Δ_i>0)、**A 中 m_i>0 的格比例**（「在幾成組合裡為正」）、
  `median(m_A) − median(m_B)` 的 bootstrap 95% CI（重抽格 2000 次，seed 固定；**註明格與格因共用成分並非獨立，
  CI 偏樂觀**）。
- **置換 null**：在同頻率內把 `m` 值在格之間隨機打散 10,000 次（保持成分成員關係不變），
  得該成分 `median(Δ)` 的 null 分布，報觀察值的百分位。**14 個檢定（7 成分×2 頻率）→ Bonferroni，
  「與雜訊可區分」門檻 = 第 99.6 百分位**。

## 5. 判定（分支，事前寫死，不得放寬）

**列為「穩健零件」（進階段三）需同時滿足（頻率 k 內）：**
1. `Δ_gross` 正貢獻比例 **≥70%**（交辦原文）；
2. `median(Δ_gross)` **>** 該頻率損益兩平線——`breakeven_alpha_table.json` 無折扣 1.0x、
   `breakeven_annual_alpha_pct_geometric`：**monthly(t20)=9.05、quarterly(t60)=2.93**
   （交辦原文「中位數超過該換倉頻率的損益兩平線」；因兩平線是**毛** alpha 概念，故此處用毛 Δ，
   避免把成本重複扣兩次）；
3. **`median(Δ_net)` > 0**（`[自行裁量]`加嚴：防止「提高換手才換到毛貢獻」的成分靠毛數字過關；
   這是「不放寬」方向的補強，不是改既有關卡門檻）。

置換 null 是否 ≥99.6 百分位**不改變上面三條的分支**，但**必須並列報告**；穩健零件若未過 null 門檻，
零件.三規格與報告一律標「與雜訊未達可區分」。

**分支**：
- ≥1 個零件（任一頻率）同時滿足 1～3 → 列穩健零件，零件.三由 BLOCKED 轉 `- [ ]`。
- 全部零件都不符合 → 誠實回報「**零件層級找不到穩健正貢獻**」，零件.三維持 BLOCKED 並註明原因為
  「階段二無穩健零件」；**不為了有東西交而放寬任何一條**。
- 中間地帶（僅符合 1～3 之一或二）→ 只描述，不列穩健。

## 7. 這份規格的已知限制（先寫，免得事後才發現）

- 因子池只有 7 個、且部分已被過去 IC 檢定不同程度否定——本圖回答「在這 7 個裡誰穩健」，
  **不代表整個因子空間**。
- 抽樣格 240 vs 總格數（子集 21+35+35=91 ×4=364）約 66%，接近窮舉；「隨機抽樣」在這裡
  更接近部分窮舉，對零件貢獻的估計比真隨機抽樣穩，但**不能宣稱是大空間的隨機樣本**。
- 格與格共用成分，統計上非獨立；bootstrap CI 與 70% 比例都因此偏樂觀，置換 null 部分補償這個問題。
- 使用宇宙若走 fallback，存活者偏誤見第 2 節但書。
