## 1. 規則（照草稿第 1 節，一字不改）

| 項目 | 規則 |
|---|---|
| 宇宙 | 每月第一個交易日，以當時在市的上市＋上櫃普通股（**含之後下市者**）排「前 60 個交易日平均成交金額」，取前 50 名。排除 ETF、權證、特別股、全額交割股。 |
| 中心與格距 | 中心＝建格當天的 60 日均線（還原權息收盤價）；格距 g＝1×ATR20（還原權息高低收，Wilder 定義）。 |
| 格線 | L₋₅…L₊₅ 共 11 條線、10 格（中心上下各 5 格）。 |
| 進場 | 每一格一個格位。收盤價由上往下跌破某格下緣 Lᵢ（i＝−5…+4）且該格位空著 → **隔日開盤**買入一份。 |
| 出場（獲利） | 每個格位在價格收盤站上該格上緣 Lᵢ₊₁ → 隔日開盤賣出。 |
| 金額 | 總資金平分給 50 檔，每檔再平分 10 個格位；每格固定金額、同一格最多一份、**不加碼、不加倍**。沒用到的資金留現金（不計利息）。 |
| 停損 | 收盤價跌破 L₋₅ → 隔日開盤該檔全部格位出清；該檔冷卻 20 個交易日不得建格。 |
| 重新建格 | 只在月初、且該檔沒有任何持倉時重算中心與格距；有持倉就沿用舊格直到清空或停損。 |
| 跌出宇宙 | 月初不在前 50 名 → 不再新買；既有格位當天開盤出清。 |
| 成交限制 | 隔日開盤漲停（買）／跌停（賣）鎖住 → 當天不成交、順延（`costs.limit_status()`）；停牌日不成交；下市以最後成交價出場。 |
| 成本 | `research/validation/costs.py`：手續費 0.1425% 雙邊、證交稅 0.3%、滑價 5bps／邊；報 1×／2×／3×。 |

- 起始：2007-01 第一個交易日建格；2009-12 最後一個交易日收盤全部按收盤價結算（不順延到 2010）。

## 2. 判準（全部通過才 PASS）

1. 交易數 ≥100（不足 → 資料不足，不檢定）。
2. **天條一**：全期 MDD ≤50%，並報 2008-05～2008-11 空頭段回撤。超過 → `VIOLATES_SURVIVAL`，不看後面。
3. **第 8 關（簡化版）**：扣 1× 成本年化報酬 > 0050 含息年化（2007-01～2009-12，既有 0050 序列）；2×、3× 成本仍淨利 >0。
4. **隨機進出場時點控制組**：`run_random_timing_control()`，同一檔、同筆數、同持有交易日數，只把進場日換成同一日曆月的其他交易日，1,000 次、`seed=20261021`、價格欄 `adj_open`、cost_rates 用真實回測同一組；網格扣成本最終權益須 **> 第 95 百分位**，並照實列出是否過全體 N 下的 Bonferroni 百分位與 `kept_original` 次數。
5. 逐年：2007、2008、2009 分別報對 0050 超額，只揭露、不否決。
