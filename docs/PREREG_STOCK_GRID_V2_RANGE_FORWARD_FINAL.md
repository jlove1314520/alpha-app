## 0. 機制與家族

- 機制（同歷史版 §0）：網格利潤來自價格在固定區間來回；#468 死在 2009 單邊上漲「太早賣光」。只在建格當下中心沒有明顯漂移的個股啟動，應能避開單邊趨勢。
- 家族：個股網格（#468）。若本線通過，與 #468 屬同一家族、只算一個發現。
- 最可能的死法（事前寫）：①建格後才走出趨勢；②濾網放行太少、等於大量現金，贏不過 0050；③24 個月內交易數不足。

## 1. 第 10 關：前向版

不用歷史段；**2027-01-04 起跑**，與模擬 J／K／L 同一套前向框架（`research/paper_forward_common.py` 的帳本、淨值、判定工具）。網格是**日頻**規則：每個交易日收盤後判斷、隔日開盤成交，追蹤程式要每個交易日跑一次（排程另案，定稿後再登記，照十節確認 allowlist）。價格只用 repo 既有官方日收盤／開盤（`data/` 官方日檔與 `data/price_history/`），不新增外部請求。

## 2. 規則（寫死，定稿後不得再改）

| 項目 | 規則 |
|---|---|
| 宇宙 | 每月第一個交易日，當時 `data/listed_universe.json` 在市的上市＋上櫃普通股（4 碼、非 0 開頭、排除 91 開頭），排「前 60 個交易日平均成交金額」取**前 50 名**。前向資料無存活者偏誤。 |
| 中心與格距 | 中心＝建格日前一交易日收盤的 **60 日均線**（還原權息收盤）；格距 g＝1×ATR(**N**)（Wilder），N＝20。 |
| 區間市濾網 | 建格前判斷 \|MA60(t) − MA60(t−N)\| ≤ g（t＝建格日前一交易日，N 同上＝20）；不符當月不建格、下個月初再判。已有持倉者沿用舊格、不受濾網影響。 |
| 格線 | 中心上下各 5 格，共 **10 格**、11 條線。 |
| 進場／出場 | 收盤由上往下跌破某格下緣且該格位空著 → 隔日開盤買一份；格位收盤站上該格上緣 → 隔日開盤賣出。 |
| 金額 | 總資金平分 50 檔、每檔再平分 10 格；每格固定金額、不加碼；未用資金留現金（不計利息）。 |
| 停損 | 收盤跌破最下緣 → 隔日開盤該檔全部出清；冷卻 N（＝20）個交易日不得建格。 |
| 重新建格／跌出宇宙 | 同 #468：只在月初且無持倉時重建；月初跌出前 50 名 → 不再新買、既有格位當天開盤出清。 |
| 成本／漲跌停 | `research/backtest/engine.py` `buy_leg_rate`／`sell_leg_rate`（1×），判定另報 2×／3×；漲跌停鎖死當天視為無法成交（`costs.limit_status()`，前向為 ±10%）。 |
| 虛擬本金 | 100 萬元；淨值用 `.github/scripts/build_strategy_curves.py`。 |

## 4. 判定（事前寫死，判一次）

- **判定日**：2029-01-02 之後第一個有收盤資料的交易日（滿 24 個月）。
- **前提**：已平倉交易（格位一進一出算一筆）≥ 100 筆；不足 → INCONCLUSIVE，不延長、不改參數。
- 全部通過才算「前向通過」：
  1. **天條一**：追蹤期間淨值最大回撤 ≤ 50%（違反即 `VIOLATES_SURVIVAL`）；
  2. **第 8 關**：扣 1× 成本後年化報酬 ＞ 同期 0050 含息（`evaluate_gate8()`）；
  3. **第 4 關**：2×、3× 成本下年化報酬仍 ＞ 0；
  4. **第 5 關**：`run_random_timing_control()` 用追蹤期間真實交易表抽 1,000 次（種子 20270104），> 第 95 百分位；`kept_original` 照實揭露；
  5. **濾網控制組**（歷史版 §2-5 沿用）：每月在「原規則會建格但不看濾網」的股票中隨機挑同樣多檔，200 次（種子 20261024），濾網版 > 第 95 百分位——分辨「濾網有用」與「只是少開格、多放現金」。這一組需要同時記錄「不加濾網」的影子網格（只記帳、不判定）。
- **揭露（不判定）**：每月濾網放行檔數與比例、資金使用率、同期不加濾網影子網格淨值。
- 通過只代表沒被否證；之後另案提部署（八節真錢規則）。任一不過 → FAIL 入墓園，附 3 個變形方向。

## 5. 已知限制

1. 日頻追蹤需要每日排程與隔日開盤價；排程漏跑照實記實際成交日，不回補。
2. 24 個月、每檔最多 10 格，交易數可能不足 100 → INCONCLUSIVE 的風險照實寫在前面。
3. 前向段不一定出現單邊大漲／大跌，濾網的價值可能測不出來。
4. 只做多，沒有借券問題。
