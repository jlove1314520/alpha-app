## 結論：分點資料母題

14 家逐一查證後，**沒有任何一家的官方 API 文件提及「券商分點買賣」或逐券商
進出籌碼資料**。與既有結論一致：**台灣分點資料的唯一合法官方管道是證交所
付費「買賣日報表」商品（NT$100,000/月），本階段不採購，不找替代爬法**
（依 `CLAUDE.md`「取得方式鐵律」）。這條演習到此可以視為窮盡合理範圍內的
免費/低成本官方管道，**沒有找到，不是沒查夠**。
