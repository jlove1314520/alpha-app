## 二、寫作規則

1. 卡片標題 ≤8 字，不加括號。
2. 按鈕 ≤6 字。
3. 說明文字 ≤40 字；超過的收進「ⓘ 說明」點開（`app.js` 會自動收，結論短句標 `data-ui-keep` 常駐）。
4. 先結論、後原因。例：紅色橫幅第一行「還沒入金，週一不會下單」，第二行「入金後自動重跑 ›」，數字收在「看細節」。
5. 研究術語（回測細節、試驗編號、DSR、端點名、檔案路徑）只放設定頁「進階」。
6. 「非投資建議」只放頁尾一處，各卡不重複。
