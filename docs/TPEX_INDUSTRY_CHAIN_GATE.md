# 櫃買產業價值鏈平台：取得可行性查證（題材庫一.1 閘門）

> 2026-09-08。總司令裁示【題材庫一】第 1 步：「先查 ic.tpex.org.tw 的 robots.txt
> 與使用條款，不可讀就停止回報，**不繞**。」
> 本檔是那一步的查證紀錄。**結論：不可讀，已停止，未撰寫任何抓取程式。**

## 結論

**櫃買中心「產業價值鏈資訊平台」的資料，目前沒有合規的自動化取得途徑。**

依 CLAUDE.md「搜尋紀律：三來源查證」，四類來源查了三類，全部指向同一結論。

## 一、官方網站（robots.txt 與使用條款）

### robots.txt：不存在

```
GET https://ic.tpex.org.tw/robots.txt
→ HTTP/1.1 302 Security Redirect
   Location: https://ic.tpex.org.tw
   （0 位元組）
```

母站也沒有：`GET https://www.tpex.org.tw/robots.txt` 回 **HTTP 200，但內容是
404 錯誤頁**——又是 CLAUDE.md 已知地雷「200 不代表成功」的同一個形狀，
只看狀態碼會誤判成「有 robots.txt 且允許」。

**沒有 robots.txt 不等於允許。** robots.txt 缺席時要看使用條款，而條款講得很明白。

### 使用條款：明文禁止爬蟲

來源：<https://www.tpex.org.tw/zh-tw/gtsm_disclaimer.html>

> 「**禁止透過包括但不限於自動化裝置、指令碼、自動程式、蜘蛛程式、爬蟲程式
> 或擷取程式等方式下載本網站之軟體或資料。**」

這一句直接涵蓋裁示【題材庫一】第 2 步要做的事（用程式抓 30+ 條
`/introduce.php?ic=<代碼>` 頁面）。**間隔拉到 3 秒也不改變它被禁止的事實**
——速率不是重點，「用程式下載」本身就是被禁的行為。

條款另提到一個例外：櫃買已授權部分資料上**政府資料開放平臺**，那部分不受此限。
於是往下查第二、三類來源。

## 二、官方 API 文件：TPEx OpenAPI 沒有這份資料

<https://www.tpex.org.tw/openapi/swagger.json>（實測 HTTP 200，477KB）

- 端點總數：**225**
- 以「產業／鏈／chain／industry」關鍵字比對，命中 **4** 個，逐一檢視全部不是價值鏈：
  - `/tpex_3insti_qfii_industry`（上櫃各產業外資買賣超）
  - `/tpex_daily_market_value`（市值排行）
  - `/t187ap46_O_13`（ESG 資訊）
  - `/mopsfin_t187ap14_O`（各產業 EPS 統計）

**官方 OpenAPI 沒有產業價值鏈端點。**

## 三、政府資料開放平臺：沒有這個資料集

`data.gov.tw` 上櫃買中心相關資料集只有：上櫃公司基本資料（25036）、
櫃買指數成分股（20216）、創櫃板公司資訊（34088）、上櫃股票收盤行情等。
這些提供的是**產業別**（我們已經有，`company_info.json` 3,047 檔），
**沒有價值鏈的上/中/下游分段**。

（註：`data.gov.tw` 的 REST 查詢端點對 GET 回 **HTTP 405 Method not allowed**，
改以平臺搜尋與資料集頁面查證。）

## 四、補充事實

2022-03-21 起，產業價值鏈資訊平台的**資訊申報作業已整併進 MOPS 電子認證申報系統**
（單一登入），管理端在 `icm.tpex.org.tw`，需帳號。
也就是說資料的上游其實是各公司自行申報到 MOPS——這替下面的替代路徑提供了線索。

## 對【題材庫一～四】的影響（重要，不是全部卡死）

**只有「骨架層」（題材庫一）被擋住，題材庫二的核心不受影響。**

總司令定義的證據等級：
- **A＝公司自述**（法說會簡報／重大訊息／年報）→ **不受影響**。
  這些走 TWSE `t187ap04_L` 與 TPEx `mopsfin_t187ap04_O` 官方 openapi，
  我們在建置一.1 已經接好且實測 200。
- **B＝價值鏈平台收錄** → **拿不到**（本檔結論）。
- **C＝新聞共現** → **不受影響**，用我們自己的 `news.json`。

**所以 `themes.json` 仍然做得出來，只是少了 B 級證據這一路。**

但這牴觸裁示【題材庫二】第 4 條的上線門檻：
「每個題材成員必須至少一筆 **A 或 B** 級證據才能上線」。
B 不可得時，該條實際上變成「**必須至少一筆 A 級**」——
門檻**變嚴**（只認公司自述），不是變鬆。

**這是規格變更，需總司令裁示，我不自行改門檻。**
