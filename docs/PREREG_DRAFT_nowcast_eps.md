## 0. 可行性診斷結果摘要（供判斷這條路值不值得正式登記）

**樣本說明（誠實揭露，非小問題）**：目標樣本 300 檔（與現有 factor_ic
登記框架同一組 seed 20260822 抽樣），但本次執行途中 FinMind 免費額度
觸發 402 冷卻，`BalanceSheet`（股本，A 版公式需要）只有已快取的子集
可用，**實際可用僅 52 檔、1,539～1,550 個股票-季觀測**。這遠小於原本
規劃的 300 檔，下列數字只能當「方向性可行性訊號」，**不能當成正式
準確度定論**——正式登記前必須先補齊 BalanceSheet 快取，用完整樣本
重跑，見§5「正式登記前置條件」。

**準確度（A 版，前一季股本子集，52 檔 1,539 筆，2014Q4～2024Q3）**：

| 指標 | est（nowcast） | 季節性 naive（去年同季 EPS） |
|---|---|---|
| 水準 Spearman（est/naive vs 實際 EPS） | 0.723 | 0.599 |
| YoY 變動 Spearman | 0.626 | — |
| 方向命中率（相對去年同季） | 73.4%（n=1,521） | naive 延續上季 YoY 方向 71.8%（n=1,512） |
| MAE（元） | 0.474 | 0.655 |
| 標準化誤差（÷過去4季\|EPS\|均值）在 ±0.25 內比例 | 28.5% | 23.1% |
| 橫斷面 IC（est vs 實際水準，40季平均，全部季轉正） | 0.720 | 0.600 |

B 版（隱含股數，全部 52 檔 1,550 筆可用）數字與 A 版非常接近（水準
Spearman 0.719、方向命中 73.6%），兩版互相印證，不是單一公式取巧的結果。
`par10股數 vs 隱含股數`比值中位數 1.003、91.2% 落在 ±10% 內，兩種股數
估法彼此一致，B 版可作為 BalanceSheet 缺漏時的合理替代，不只是備援。

**誠實讀法**：

1. Nowcast 水準相關（0.72）明顯優於單純季節性 naive（0.60），**這部分
   訊號是真的**——用當季已公布月營收確實比「假設今年跟去年一樣」更準。
2. 但**方向命中率的增量很小**（73.4% vs 71.8%，只贏 1.6 個百分點），
   而 naive 基準本身已經因為「多數公司大多數季度都賺錢」而有 50%+ 的
   base rate 優勢（`sign_profit_hit` 79% vs base rate 73%，這條本身
   資訊量不大，不是判斷依據）。**若正式登記，判準必須用「相對 naive
   延續基準的增量」而非絕對命中率，避免把base rate的功勞算給模型**。
3. **可交易窗口（T_n→法定截止日）Q1–Q3 平均僅 24–25 個交易日，Q4 因
   跨年報延後到 3/31（2013年前4/30）而長達約 50 個交易日**——這代表
   Q4 這一季的「提前知道」優勢視窗特別寬，**必須提防這正是析.一§1
   診斷出的同一個 Q4 前視偽影的另一種形狀**：Q4 視窗長不是因為預估
   本身更準，是因為法定截止日離月營收公告更遠。正式登記時 Q4 的
   進場/判準必須與 Q1–Q3 分開報告，不得合併稀釋。
4. Q4 direction_hit（73.0%）與其他季相近，沒有出現析.一§1那種「Q4
   異常高」的訊號，初步看不像是同一偽影在nowcast上重演，但**樣本小
   （52檔）不足以下定論**，正式登記時要重驗。

## 1. 假設（若正式登記，暫定版本，待審閱後定案）

- **核心假設**：當季三個月月營收已完整公布、但財報尚未公布這段窗口
  （Q1–Q3 約 24 日、Q4 約 50 日），市場尚未完全消化「用月營收可推算
  出的當季獲利水準」，此時進場的股票在財報公布後能有超額報酬。
- 這是**析.二.2 正確 PIT 事件研究**（`docs/EPS_REVENUE_SIGNAL_
  ANATOMY_2026-09-29.md` §2）的延伸：該診斷已顯示公布後 1–20 個交易日
  有正向 IC（PEAD 型漂移），本假設進一步問「能不能在財報公布前，靠
  nowcast EPS 提早卡位」。

## 2. 進出場規則（暫定，未定案）

- **訊號**：`nowcast_surprise = (est_EPS − 去年同季EPS) / scale`，
  scale＝過去4季\|EPS\|均值（與析.二誤差正規化口徑一致）；或用
  `est_EPS` 相對分析師/歷史共識的意外值（若析.二.4查到合規共識資料源，
  改用真共識；查無則退回本診斷的簡單模型）。
- **進場時點**：T_n（該季第3個月營收 PIT 公布日）後第一個交易日。
- **出場時點**：財報法定截止日後第 N 個交易日（N 待掃描，依析.一§2
  PEAD 衰減曲線，候選窗口 5～20 個交易日）；或財報公布日（若早於法定
  截止日）後平倉，兩種出場規則都要各自測。
- **Q1–Q3 與 Q4 分開報告**（理由見上）。
- **多空**：初版只測多頭（nowcast_surprise 高分做多），因借券成本/
  可借量未接入真實資料（`CLAUDE.md`七之三⑩），空頭腿依既有硬規則
  一律不得採信。

## 3. 判準（沿用既有六關＋新增四關框架，凍結.二解除後才適用）

- 天條一（MDD≤50%，硬約束）、被動基準對照（第8關，0050/TAIEX加權
  持有）、參數高原、成本敏感度（1×/2×/3×）、相鄰頻率一致性（若做
  多檔同時持有，測不同持有天數 N 的一致性）、隨機控制組（同頻率隨機
  進場 vs 本訊號）、leave-one-year-out、樣本外（val/holdout切分，
  holdout 未經總司令同意不得解鎖）、absorbing state 檢查（若加停損/
  停利機制）。
- **判準核心用「相對季節性 naive 延續基準的增量」**，不是絕對報酬——
  依§0.2的教訓，nowcast 的邊際價值必須明確剝離「多數公司多數季度
  獲利為正」這個 base rate。

## 附錄：FinMind 以外的券商共識預估 EPS 資料源查證（析.二.4，2026-09-29）

依`CLAUDE.md`「搜尋紀律：三來源查證」，查了以下多個獨立來源（官方網站／官方API文件／GitHub社群／其他供應商四類皆涵蓋），結論一致
——**台灣沒有免費/官方的共識預估EPS資料源，這類資料本質上是第三方
分析師研究成果的商業彙整品，不是公司對外揭露義務的一部分**：

1. **台灣經濟新報（TEJ）**——台灣本土最大財經資料商，`api.tej.com.tw`
   有完整API，`eshop.tej.com.tw`列出「小資方案」「達人方案」等分級
   訂閱方案，但**方案定價未在官網公開列出具體金額**，需申請試用
   key或聯繫業務（電話 02-87681088#120、email tej@tej.com.tw）才能
   取得報價。是否含機構預估EPS欄位需另外確認資料字典。
2. **CMoney（理財寶／法人投資決策支援系統）**——`cmoney.com.tw`
   明確有「法人機構預估盈餘」產品，彙整券商研究報告的EPS/營收/毛利
   預估，是市面上台股散戶最常見的共識預估來源，但**同樣是付費產品，
   官網未列公開定價**，需查詢官網或聯繫客服。
3. **官方揭露系統（公開資訊觀測站 MOPS）不提供此類資料**——MOPS是
   上市櫃公司**法定揭露義務**的平台（財報／重大訊息／月營收），
   結構上不會收錄第三方分析師的預估研究，因為那不是公司揭露義務
   的一部分，是分析師的獨立研究成果。搜尋未找到MOPS有任何共識預估
   EPS端點，與這個結構性理由一致（本項屬結構性推論＋搜尋未見反例，
   非逐頁地毯式排除，誠實標註信心等級較弱於前兩項）。

4. **官方 OpenAPI（`openapi.twse.com.tw` swagger v1.0，2026-09-29 抓取，
   143 個端點逐一比對關鍵字）**——**有兩類相關但不等價的端點**：
   `/opendata/t187ap15_L`（上市公司截至各季綜合損益財測達成情形）與
   `/opendata/t187ap16_L`（當季查核數與預測數差異≥10%者）。**這是公司
   管理層自編的財測（僅有自願公開財測的公司才有），不是分析師共識**，
   涵蓋率、歷史深度（是否只有當期快照）**本次未驗證**，待要用時先抽樣
   確認。對本 nowcast 的價值：可當「管理層預測 vs 營收推算」的第二個
   對照，而非共識替代品。
5. **社群／開源（GitHub）**：`yikuochan/fadacai-portfolio` issue #14
   （2026-09-29 讀取）記載「中小型櫃買股缺程式化共識預估資料」為已知
   缺口，與上面「無免費官方來源」的結論一致。
6. **國際資料商**：LSEG（原 Refinitiv）I/B/E/S 預估資料有 RDP Estimates
   API，屬可授權商業資料，**官網無公開定價**；TEJ 的 API 說明頁未列出
   共識預估資料庫。價格一律標「待採購／需詢價」，不估算數字。
7. **不可用（顯示型網站，禁止爬取）**：Goodinfo、MoneyDJ、鉅亨網等只
   提供網頁顯示、無授權 API，依「取得方式鐵律」不爬取，僅供人工參考。

**補充參考（非可用來源，僅供費用量級參考）**：國際資料商 FactSet
也提供台股分析師共識EPS（例如台積電的分析師調查），但屬企業級授權，
