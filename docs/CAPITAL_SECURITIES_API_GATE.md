## 三來源查證（依 CLAUDE.md「搜尋紀律」）

### 來源 1：官方網站（capital.com.tw）
`https://www.capital.com.tw/web/#/download/ApiTrading/ApiTradinginfo`——
確認頁面存在（見 WebSearch 摘要：「群益 API功能包含國內證期選、海外期選

### 來源 2：GitHub（第三方 Python SDK，實際串接過官方元件）
`https://github.com/AlexChiang0208/capital_api`——SDK 涵蓋：
- **報價**：快照、逐筆成交、五檔報價、歷史 K 線
- **下單**：現貨（限價/市價/漲跌停）、期貨、選擇權、價差單
- **回報**：委託/成交即時回報、同步查詢
- **帳務**：持倉、庫存、掛單、購買力查詢
- **逐筆串流**：自動補洞、斷線重連
- 明確提到：「未簽署證券/期貨 API 下單聲明書，對應市場商品檔不會下載」，
  且帳號需有「該市場行情權限」——**印證申請門檻**。
- **未提及官方模擬/測試環境**；SDK 自帶的 `enable_live_order=False` 是本地
  端 dry-run（只組 payload 不送單），**不是群益提供的官方模擬環境**。
- **未涉及分點/券商買賣統計資料**。

### 來源 3：券商官方部落格（申請流程說明）＋程式碼範例
`https://www.keenspie.com/blog.php?act=view&id=61`（群益期貨金牌團隊部落格）：

  「期貨API下單服務聲明書」（第15項文件，本人身分）

`https://gist.github.com/f107110126/8d7ca155a5d2a4c69dba6a9a97d69fb4`（報價

## 為什麼步驟 2 是本輪停下點

依 `alpha-app/CLAUDE.md`「三個停下條件」第 1 條「需要總司令親自操作（登入、
實機測試、花錢、要他裁示）」——群益 API 的申請鏈完全綁在總司令的個人身分：

1. 必須是群益的**開戶客戶**（帳號是總司令的，不是 CC 能代辦的）。
2. 驗證小工具的三項模擬測試**在本機互動執行**，且很可能需要總司令的看盤/
   下單密碼。
3. 「期貨API下單服務聲明書」是**本人身分認證的簽署文件**，CC 沒有總司令的
   身分憑證去簽。

CC 能做的（查文件、列功能、回答分點演習）已經做完；**接下來需要總司令決定
要不要申請、並親自完成申請與簽署**，之後才輪得到 CC 接程式碶（憑證放
`.env`/`secrets/`，絕不進 repo，沿用既有 Shioaji/IBKR 憑證處理慣例）。
