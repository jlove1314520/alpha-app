## 1. 構造（全部事前固定，單一組合，不掃描）

| 項目 | 不傾斜臂（基準） | 傾斜臂（試驗） |
|---|---|---|
| 成分 | 第 0 階段量尺的成分與異動日（`taiwan50_schedule()`） | 同左，一檔不多一檔不少（不加非名單股，`non_list_cap=0`） |
| 權重 | 異動日總市值權重，之後隨價格漂移 | 每 21 個交易日（以 2013-06-03 為第 1 個再平衡日）及每次成分異動日：取不傾斜臂**當天漂移後的權重** w，加上傾斜 Δw |
| 傾斜 Δw | — | 沿用 `core_tilt_backtest.build_target_weights()` 的映射：成分內 `A_4pass` 綜合分數（`pb2.FACTOR_VERSIONS["A_4pass"]`＝eps_family＋revenue_surprise＋low_vol，equal 加權，不改）做 min-max 映射到 [−1, 1]，乘 **2pp**，截在 ±2pp；w+Δw 小於 0 截為 0 後重新正規化；產業偏離超過 **±3pp** 依原程式縮放。沒有分數的成分 Δw＝0 |
| 兩次再平衡之間 | 買進持有 | 買進持有 |
| 成本 | 自己的換手（成分異動） | 自己的換手（成分異動＋每次重新傾斜） |

- **成本 1×**＝`research/validation/costs.py::round_trip_cost_pct()` 預設（手續費全額、證交稅 0.3%、預設滑價），按每次再平衡的單邊換手計；**2×、3×**＝1× 乘 2、乘 3。
- **事前寫死的實作細節**（程式 `research/core_tilt_v2_stage1.py`，跑之前已 commit）：
  - 「有分數」＝`pb2.compute_composite_at_date()`（只餵當期成分，產業內 z-score 沿用 `score._zscore_within_group`）後再過 `pb2._eligible()`（成分數 ≥ `score.MIN_COMPONENTS_FOR_RANKING`、成分內 20 日均成交金額後 10% 剔除）——與 `build_target_weights()` 同一條路徑。沒過的成分 Δw＝0。
  - 傾斜再平衡在第 d 天**收盤**定權重、第 d+1 天起生效；成分異動則在官方 weight_day 收盤定權重（同量尺），傾斜也在同一天收盤加上。
  - 成本＝單邊換手 0.5×Σ|新權重−漂移後權重| × `round_trip_cost_pct()`（預設 0.685%），扣在新權重生效的第一天。
  - 年化超額＝判定期傾斜臂淨值 CAGR − 不傾斜臂淨值 CAGR（日報酬連乘、252 日年化）。TE＝兩臂日報酬差的標準差 ×√252。
  - 引擎核對：重算的不傾斜臂日報酬與 `build_portfolio()` 最大差須 < 1e-9，否則不跑。
- 因子分數只用當天以前已公告的資料（`compute_composite_at_date()` 既有 PIT 規則：財報用公告日、營收用公布日）。

## 3. 判定（全部事前寫死；全過才 PASS）

**主判定量**：判定期「傾斜臂 − 不傾斜臂」的年化超額報酬（兩臂各扣自己的成本）。

1. **超額 > 0**（成本 1×）。
2. **成本敏感度**：成本 2×、3× 時超額仍 > 0。
3. **隨機對照組**：1,000 次，每次在每個再平衡日把成分的 `A_4pass` 分數**在成分內隨機重排**（傾斜幅度、產業 ±3pp、再平衡日、成本全部相同，只有「誰加碼誰減碼」是隨機的），種子 20261014。真實超額要 **> 第 95 百分位**（只贏平均不算）。
4. **天條一（硬約束，先於上面三條檢查）**：傾斜臂全期與判定期最大回撤 ≤ 50%；另逐段列出空頭段回撤（2015-04～2016-01、2018-01～2018-12、2020-01～2020-03、2022-01～2022-10）（月份是概略標示，執行時以加權指數實際峰谷日為準，不另挑）。任一超過 50% → 直接判 `VIOLATES_SURVIVAL`，不看其他條。
5. **追蹤誤差上限（防假性超額）**：判定期傾斜臂對不傾斜臂的年化 TE 須 ≤ 3%；超過代表傾斜已不是「小幅」，判 FAIL（不是調小重跑）。

**只報告、不作主判定**（裁示）：傾斜臂、不傾斜臂各自對 **0050 官方 NAV 含息**的年化超額、TE、逐年勝負（「贏過基準的年數／總年數」，天條三排序用）；同期 0050 市價含息也並列。

**另報**：每次再平衡有分數的成分檔數與權重覆蓋率、平均單邊換手、台積電權重兩臂差、DSR（附 V 的來源與樣本數，CLAUDE.md 七之三）。

## 6. 已知限制（照實寫）

1. **判定期不是乾淨資料**：2021–2024 曾被舊版 #283 使用（淨值平線、視為未有效看過結果，見第 2 節）；此外`A_4pass` 的成分是在看過驗證期 IC 之後選定的（`portfolio_backtest_v2.py` 的 IC 權重來自 val 期），2021～2024 也被其他試驗用過。所以加隨機對照組，且通過也只能算「判定期內站得住」，不是真樣本外。
2. 量尺本身對 0050 NAV 有 1.70% 日頻 TE；主判定兩臂相減可抵銷大部分，但傾斜幅度相對權重的部分不會完全抵銷。
3. 自由流通係數缺資料（N1），台積電在兩臂都偏低；若傾斜傾向減碼台積電，對「真 0050」的實際效果會跟這裡不同（另報欄位會看得到）。
4. 放空：本試驗不做空（Δw 只是在名單內加減權重，最低 0），不受「放空腿資料缺陷」規則影響。
