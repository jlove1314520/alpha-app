## 樣本與驗證段
2007-01-02～2014-12-31（8 個年度），母體如上（時點宇宙）。

## 訊號／規則（參數一次定死）
- 策略：t0（2007-01-02 收盤）等權買入全部母體股，之後每 21 個交易日（相位：t0 起算）把仍在市的股票拉回等權；
- 基準：同一組股票 t0 等權後不再平衡（buy-and-hold；下市股同樣以最後收盤出場、持現金）；
- 成本：`research/validation/costs.py` `round_trip_cost_pct()`（一般股票）1×，依每次再平衡的實際換手收；另報 2×／3×。

## 檢定與判準（事前寫死）
依序：
1. sanity：全期溢酬（策略 − 基準，扣 1× 成本）> 0；
2. 隨機控制組：每次從母體隨機抽一半股票（種子 20261018＋i，i＝0～99）重算溢酬，N＝100，溢酬 > 0 的比例 ≥ 95%；
3. 逐年一致：8 個年度中溢酬為正 ≥ 7 年（原門檻 5/6＝83.3% → 8 年取 7/8）；
4. 成本 3× 時全期溢酬仍 > 0；
5. **第 8 關被動基準（先.一一四-3b）**：策略扣 1× 成本後的年化報酬要**贏過同期 0050 含息年化報酬**（2007-01-02～2014-12-31），沒贏就判 FAIL。
全部通過 → PASS（代表這個機制在時點宇宙的新資料段仍成立；部署另案）。任一不過 → FAIL。

## 天條一（硬約束）
- 報告策略與基準在 2007～2014 全期最大回撤，以及兩個空頭段的回撤：2007-10-30～2008-11-21（金融海嘯）、2011-05-02～2011-12-19（歐債）。
- 回撤以日收盤淨值（扣成本後）計；下市股以最後收盤計價、之後持現金。
- 任一段超過 50% → `VIOLATES_SURVIVAL`，不進後續判定，不論溢酬多顯著。

## 檢定力
8 個年度、約 95 次再平衡；逐年一致只有 8 個觀測，檢定力有限，PASS 只當「流程對且新段仍成立」的證據。

## 已知限制
- 時點宇宙依賴官方上市日期與下市名單；涵蓋率未達 95% 不跑（見「資料」）。
- 價格只做股利還原；分割、減資、面額變更未納入（2007～2014 少見）。
- 等權母體含大量小型股，2008 年回撤可能接近天條一門檻。

## 只跑一次／holdout／登記
- 參數全部寫死在本文件；資料備妥且涵蓋率達標後，先 `register_trial()`（綁程式 commit）事前登記，再跑**一次**，結果不論好壞照登，不得改參數重跑。

- 計入 N：**+1**。FAIL 時照 CLAUDE.md 七之三附 ≥3 個變形方向。
