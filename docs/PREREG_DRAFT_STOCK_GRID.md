## 0. 為什麼要測、為什麼不做馬丁格爾

- 查 `research/TRIALS_LEDGER.md`／`TRIALS_REGISTRY.jsonl`／`STRATEGY_GRAVEYARD.md`／`HYPOTHESIS_QUEUE.md`：**任何軌都沒有網格（grid）試驗**；台股個股也沒有任何「單股、以波動度定格距」的時間序列試驗。
- 馬丁格爾（虧損加倍攤平）不做：部位隨虧損指數放大，結構上就是賭「不會一路跌到底」，違反天條一（MDD ≤50%）。本草稿的網格每格固定金額、每格最多一份、跌破底格全部停損，**最大曝險事前封頂**。

## 1. 規則（事前寫死，不調參）

| 項目 | 規則 |
|---|---|
| 宇宙 | 每月第一個交易日，以當時在市的上市＋上櫃普通股（**含之後下市者**）排「前 60 個交易日平均成交金額」，取前 50 名。排除 ETF、權證、特別股、全額交割股。 |
| 中心與格距 | 中心＝建格當天的 60 日均線（還原權息收盤價）；格距 g＝1×ATR20（還原權息高低收，Wilder 定義）。 |
| 格線 | L₋₅…L₊₅ 共 11 條線、10 格（中心上下各 5 格）。 |
| 進場 | 每一格一個「格位」。收盤價由上往下跌破某格下緣 Lᵢ（i＝−5…+4）且該格位空著 → **隔日開盤**買入一份。 |
| 出場（獲利） | 每個格位在價格收盤站上該格上緣 Lᵢ₊₁ → 隔日開盤賣出。 |
| 金額 | 總資金平分給 50 檔，每檔再平分 10 個格位；**每格固定金額、同一格最多一份、不加碼、不加倍**。沒用到的資金留現金（不計利息，照實揭露現金拖累）。 |
| 停損 | 收盤價跌破 L₋₅ → 隔日開盤該檔全部格位出清；該檔冷卻 20 個交易日不得建格。 |
| 重新建格 | 只在月初、且該檔沒有任何持倉時重算中心與格距；有持倉就沿用舊格直到清空或停損。 |
| 跌出宇宙 | 月初不在前 50 名 → 不再新買；既有格位當天開盤出清（[自行裁量]：選最少參數的處理，避免持有不在宇宙的部位）。 |
| 成交限制 | 隔日開盤漲停（買）／跌停（賣）鎖住 → 當天不成交、順延（`costs.limit_status()`）；停牌日不成交。 |
| 成本 | `research/validation/costs.py`：手續費 0.1425% 雙邊、證交稅 0.3%（賣出、非當沖）、滑價 5bps／邊（佔位值，未實測校準）；報 1×／2×／3×（`BacktestConfig.cost_multiplier`）。 |

**為什麼用隔日開盤成交**：避免用「觸發當天收盤價」成交的前視（網格的觸發和成交如果用同一根 K 棒，會系統性高估）。代價是跳空時成交價比格線差，照實算進去。

## 2. 跟已結案的「短期反轉」比，機制差在哪

| | 已結案反轉類（#46、#87、#452、#83） | 本網格 |
|---|---|---|
| 比較對象 | **橫斷面**：跟其他股票比誰跌最多（#46 −21 日報酬排序、#87 −5 日、#452 一到十月最差 20%） | **單股時間序列**：只跟自己的 60 日均線比 |
| 尺度 | 原始報酬 | 以 ATR20 標準化（波動大的股票格子自動放寬） |
| 獲利來源 | 輸家下期相對反彈 | 同一檔在區間內**來回震盪的次數**，每次賺一格 |
| 出場 | 固定持有期 | 價格到上一格就賣；跌破底格硬停損 |
| 最接近的已死親戚 | #83 配對交易（價差 z-score，FAIL 第 2 關）、#236 台指期 Keltner 通道（EMA20±2×ATR10，FAIL 百分位 78.8）、#285/286 原子 `ts_mean(true_range)` | — |

誠實揭露：網格本質仍是「均值回歸」家族。#46／#87 的 VAL 期 IC 接近 0 或翻負，代表台股個股短期反轉在 2021～2024 不明顯；網格要贏，靠的是**區間震盪頻率**，而不是「跌最多的下月會漲」。若台股大型股多半是趨勢走勢，網格會在下跌趨勢裡被停損、在上漲趨勢裡太早賣光，這是本設計最可能的死法。

## 4. 判準（事前寫死，全部通過才算 PASS）

1. **交易數 ≥100**（六關系列第 6 關）。50 檔×36 個月預期遠超過，不足就判資料不足、不檢定。
2. **天條一**：全期 MDD ≤50%，並報 2008-05～11 空頭段回撤（`segment_mdd()`，`research/fut_basis_mr60_survival_gate.py`）。超過 → `VIOLATES_SURVIVAL`，不看後面。
3. **第 8 關**：扣 1× 成本後年化報酬 > 0050 含息（2003-06-30 起有序列）。`evaluate_gate8()` 現有結果檔只有 TRAIN（到 2020）與 VAL（2021–2024）兩期，沒有 2007 段 → 改用「扣成本年化贏 0050 含息」的簡化版（同 V1 草稿做法），2×、3× 成本另報、需仍 >0 淨利。
4. **隨機進出場控制組**：同一檔、同一批建格月份、**同樣筆數與同樣持有天數分布**，只把進場日隨機換成該月其他交易日，跑 1,000 次；網格扣成本報酬須 **超過控制組第 95 百分位**（並報全體 N 下的 Bonferroni 門檻百分位，目前 99.9886，照實列出是否也過）。
   - 現有 `research/validation/control_group.py` 的 `run_matched_control_group()` 是「換股票」不是「換時點」，**沒有現成工具**；要在 `research/validation/` 新增（第十三節：只能由互動視窗寫），核准後再做，且寫完先自測再登記。
5. **逐年**：2007、2008、2009 三年分別報超額，不作否決（樣本太少），只揭露。

## 5. 自由參數（第 11 關）

本機制有 7 個參數：宇宙 50 檔、流動性回看 60 日、均線 60 日、上下各 5 格、格距 1×ATR、ATR 20 日、冷卻 20 日。**超過 5 個**，依第 11 關逐一寫理由：

| 參數 | 值 | 理由（全部由 Cowork 派工事前給定，沒有看任何結果） |
|---|---|---|
| 宇宙大小 | 50 | 只做流動性最好的股票，避免滑價與鎖漲跌停吃掉格差 |
| 流動性回看 | 60 日 | 與均線同長度，少一個獨立選擇 |
| 均線 | 60 日 | 約一季，常見的中期中心 |
| 格數 | 上下各 5 | 封頂最大曝險（10 份），跌 5 個 ATR 才停損 |
| 格距 | 1×ATR | 格子跟日波動同尺度，一般震盪就能觸發 |
| ATR | 20 日 | 約一個月，與月初建格頻率一致 |
| 冷卻 | 20 日 | 停損後一個月不碰，避免在下跌趨勢裡反覆建格 |

**不掃參數**：只跑上面這一組。`research/selection_bias_ledger.py` 目前**沒有實作**「參數數量計入多重比較懲罰」（查程式碼確認），所以 N 只能 +1 登記；第 11 關要求的參數懲罰請總司令裁示怎麼算（建議：比照「7 個參數＝7 次試驗」計 N+7，較保守）。
