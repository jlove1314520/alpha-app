# 波動溢價：哪些路線做、哪些不做（2026-10-14）

## 模擬 F 賣波動（先.九十一-1）
- 依據：試驗 #444（`docs/PREREG_txo_vrp_2002_2014_FINAL.md`）PASS——2002–2014 台指選擇權隱含波動度平均比事後實際波動高約 3 個百分點；每月賣一組價平跨式，扣滑價、手續費與期交稅後月均約 +0.38%。
- **學界已知現象、只是研究。不提請真錢**（總司令裁示）：
  - 試驗間比較數字（DSR）算不出來；
  - 年化約 4.6%，低於持有大盤；
  - 每組 1 倍名目約數百萬元；
  - 選擇權真錢需另案核准。
- 做法：2026-11 起每月記一組價平跨式的假想損益（`research/paper_5_vrp_tracker.py`），每天用期交所收盤重估，到期用官方最後結算價；**不倒填**。App「跟 0050 比」的「模擬 F」分頁與研究成績單都標「學界已知現象、只是研究」。

## 權證：不能拿來賺波動溢價（先.九十一-5-1）
- 台股權證由券商發行，**散戶只能買、不能賣出（發行）**。
- 買權證＝付出隱含波動度，站在「付波動溢價」的一方，跟 #444 的賣方方向相反；平均來說是把溢價付給發行券商。
- 所以「用權證賺波動溢價」這條路不做。權證只當**買方工具**另外研究（先.九十二-B：低隱含波動買進、事件前買進、發行券商定價比較；先查資料、不登記試驗）。
